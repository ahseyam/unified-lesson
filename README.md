# نظام الحصة الموحَّدة — مدارس ابن خلدون

> من ورقة تحضير المعلم إلى درجةٍ موثَّقةٍ بشاهد — نظامٌ واحدٌ متكامل، استعداداً لزيارة التقويم الخارجي.

**افتح [`index.html`](index.html) — فهو المسار المجمَّع لكل ما في هذا المستودع.**

---

## ما في النظام

| الأداة | الوصف | المجلد |
|---|---|---|
| **استمارة الملاحظة الصفية** | ٨ مجالات · ٥٠ مؤشراً · ٢٠٠ درجة · أربعة مستويات و«لا ينطبق» | `٢ - استمارة الملاحظة الصفية` |
| **نموذج تحضير الحصة** | توأمُ الاستمارة: كل خانةٍ يقابلها مؤشر | `١ - نموذج تحضير الحصة` |
| **نماذج معبّأة استرشادية** | ٥٤ نموذجاً: ٣ مراحل × ٩ موادّ × الجنسين | `١ - .../نماذج معبّأة استرشادية` |
| **دليل مستويات الأداء** | لكل مؤشر: ما الذي يُعدّ شاهداً وما الذي لا يُعدّ | `٣ - الأدوات المساندة` |
| **بنك إستراتيجيات التدريس** | ١٩ بطاقة تشخيص × ١٠ مؤشرات × ١٠٠ درجة | `٤ - بطاقات إستراتيجيات التدريس` |
| **الاتجاهات التدريسية** | ٦ نشرات بأمثلةٍ من كل مادة | `٥ - الاتجاهات التدريسية` |
| **بطاقة زيارة الأقران وبطاقة الجسر** | إجراءٌ واحد يُنقل ويُتحقق منه في الزيارة التالية | `٦ - ...` و `٣ - ...` |
| **آلية الحصص الموحَّدة وجداولها** | ٣ مقيّمين + معلمان زائران · دورانٌ بمربّع لاتيني · وطني وعالمي | `٧ - آلية جداول الحصص الموحَّدة` |
| **النموذج الرقمي** | صفحة المعلم وصفحة الزائر — بلا خادمٍ ولا تنصيب | `٨ - النموذج الرقمي (تجربة)` |
| **العرض التعريفي وسيناريوه** | ٢٢ شريحة · نحو ١١ دقيقة | `٩ - العرض التعريفي` |

## قواعد النظام

- **الشاهد يُرى لا يُفترض** — ما لم يرصده المقيّم بعينه أو يطّلع عليه موثَّقاً فلا يُحتسب.
- **«لا ينطبق» تطرح ٤ من المقام** — فلا يُحاسَب المعلم على مؤشرٍ لا يتصوّر في طبيعة حصته.
- **الإستراتيجية تُقاس لا تُذكر** — بطاقة تشخيصها من ١٠٠ تتحوّل إلى درجة مؤشرها: ٩٠٪ ← ٤ · ٧٥ ← ٣ · ٥٠ ← ٢ · أقل ← ١.
- **لكل أداةٍ نسختان** — بنين وبنات، والتأنيث يشمل الفعل والضمير لا الاسم وحده.

## البناء

كل المخرجات مولَّدةٌ ببرامج في `_المولّد/` (بايثون + python-docx + openpyxl)، فتُعاد بناؤها كاملةً بأمرٍ واحد
ولا تُحرَّر يدوياً. والمحتوى مصدرٌ واحد لكل أداة، فلا تفترق الورقة عن الشاشة.

```bash
CLS_FONTSET=js CLS_GENDER=m python3 _المولّد/zbuild2.py "…/استمارة الملاحظة الصفية — ابن خلدون.docx"
python3 _المولّد/hub.py        # إعادة بناء index.html من شجرة الملفات
```
